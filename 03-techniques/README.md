# 03 — Techniques: Portfolio Management Mechanics

Strategy tells you *what* to believe about markets; technique is *how you run the money* day to day. This section covers the practical machinery of managing a portfolio — the decisions every investor makes whether they think about them or not: how to split money between stocks and bonds, how fast to invest a windfall, when to rebalance, how big any single position should be, how to use the tax code instead of being used by it, how much to withdraw in retirement, where to park cash, and how to know whether any of it is working.

Each file is written for a smart reader with no finance background. Jargon is defined where it appears, worked numeric examples show the mechanics, and every file ends with a step-by-step "How to actually do it" section, a short list of takeaways, and links to the primary sources — Bogleheads, Vanguard, Morningstar, Kitces, Early Retirement Now, Portfolio Charts and the underlying academic papers. Figures that change with market conditions (yields, safe-withdrawal estimates) are date-stamped.
