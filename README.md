# Occupy AI — The Investing Knowledge Library

A curated, sourced, plain-language library of investment strategy, technique, analysis, market indicators, and the accumulated wisdom of the best investors. Every file is written in the same shape — a one-sentence summary, the substance, how to actually do it, key takeaways, and the sources it was built from — so you can read any page cold.

**209 files · ~335,000 words · 11 sections · researched and verified September 2026.**

> **Not financial advice.** This library is educational. Nothing here is a recommendation to buy or sell anything. Fund tickers appear only as examples of a *type* of fund. Tax figures are U.S. federal rules for the 2026 tax year unless stated otherwise and change every year — confirm against IRS.gov before acting. Talk to a fee-only fiduciary advisor for decisions about your own situation.

## The library

### [01 — Foundations](01-foundations/)
Core principles (compounding, cost, diversification, real vs nominal returns with the historical numbers), asset classes, risk and return, how markets work, account types with 2026 limits, and a 117-term glossary.

### [02 — Strategies](02-strategies/)

Reading financial statements and 10-Ks, the key ratios (reference table), valuation methods with a worked DCF, moats, management and capital allocation, stock screening recipes, technical analysis and chart patterns (with what the evidence actually says), bond analysis, ETF due diligence.

### [09 — Behavioral Finance](09-behavioral-finance/)

### [10 — Checklists and Templates](10-checklists-and-templates/)

### [11 — Crypto](11-crypto/)

Written evenhandedly — the bear case gets equal time.

## How this library was built

Each section was researched from primary and authoritative sources (SEC, IRS, Federal Reserve/FRED, S&P SPIVA, Vanguard/Morningstar research, Berkshire letters, academic papers, Bogleheads wiki, and the writers' own published work), synthesized in plain language, then independently fact-checked. Where a number could not be confirmed from a primary source, the text says so ("widely reported", "approximately"). Current market readings are date-stamped and will go stale; the frameworks around them won't.

## Conventions

- Every non-index file: `# Title` → **In one sentence** → body → *How to actually do it / How to use it* → *Key takeaways* → *Sources*.
- Folder numbers are a suggested reading order, not a hierarchy.
- Jargon is defined inline the first time it appears; the [glossary](01-foundations/glossary.md) has the rest.
