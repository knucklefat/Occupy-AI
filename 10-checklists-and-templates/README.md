# 10 — Checklists and Templates

**In one sentence:** This section turns the rest of the library into action — ready-to-use checklists, fill-in templates, and step-by-step playbooks you can print, copy into a notes app, and actually follow.

Knowing what to do and doing it under pressure are different skills. Surgeons, pilots, and the best investors (Pabrai, Spier, Buffett's acquisition criteria) all rely on written checklists for the same reason: memory and judgment degrade exactly when the stakes are highest. Every file here is built to be used, not read once. Checklists use checkboxes so you can work through them; templates are fill-in-the-blank with a completed example; playbooks are numbered so a stressed person can follow them. Each ends with the published sources it was drawn from. Start with the 30-day plan if you're new, the IPS template if you have a portfolio but no written plan, and the crash playbook before you need it.

## How the files fit together

1. **Build:** 30-day plan → IPS template → fund selection checklist.
2. **Maintain:** quarterly portfolio review → annual checkup.
3. **Decide:** pre-trade checklist → stock research checklist (if you pick stocks) → formulas.
4. **Protect:** scam checklist (always) → crash playbook (when it happens) → retirement readiness (when it's time).
